# MyCapture 지원

MyCapture는 화면 캡처, 주석 편집, 화면 고정, 로컬 OCR, 라이브러리, 영역 녹화를 한곳에 모은 Windows 11용 캡처 도구입니다. 이 저장소는 사용자 지원과 공개 문서를 위한 곳이며, 앱의 소스 코드는 포함하지 않습니다.

## 설치

MyCapture는 [Microsoft Store](https://apps.microsoft.com/detail/9PB33MC095VR)에서 설치합니다. Store 설치본은 Microsoft가 서명하며, 업데이트도 Microsoft Store가 제공합니다.

- 지원 환경: Windows 11 버전 21H2(빌드 22000) 이상, x64
- 로그인 시 자동 시작은 처음에 꺼져 있으며 설정 > 일반에서 켤 수 있습니다.
- 설정과 라이브러리는 앱 전용 폴더에 저장되며 앱을 제거하면 함께 삭제됩니다. 라이브러리를 유지하려면 설정에서 캡처 폴더를 다른 위치로 지정하십시오.

## 문의

- 문제 신고와 기능 제안은 [새 이슈](https://github.com/sukwoo0711-maker/mycapture-support/issues/new)로 남겨 주십시오. Windows 버전, MyCapture 버전, 재현 단계를 함께 적어 주시면 확인이 빠릅니다.
- 캡처 이미지에 개인정보가 보이면 가린 뒤 첨부하십시오. MyCapture의 빠른 가리기(`Ctrl+Shift+R`)를 쓸 수 있습니다.
- 보안 문제는 공개 이슈에 올리지 말고 [비공개 보안 신고](https://github.com/sukwoo0711-maker/mycapture-support/security/advisories/new)를 이용하십시오.

# MyCapture support

MyCapture is a Windows 11 capture tool that brings screenshots, annotation, pinning, on-device OCR, a capture library and region recording together. This repository hosts user support and public documents; it does not contain the app's source code.

- Install MyCapture from the [Microsoft Store](https://apps.microsoft.com/detail/9PB33MC095VR). Updates are delivered by the Store.
- Report problems or suggest features in a [new issue](https://github.com/sukwoo0711-maker/mycapture-support/issues/new). Report security issues privately through [a security advisory](https://github.com/sukwoo0711-maker/mycapture-support/security/advisories/new).
